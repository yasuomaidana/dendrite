# dendrite ref

Manage Tier 1 source references for library reuse and cleanroom synthesis

## Category

Dendritic Arbor

## Aliases

- `dendritic-afferent`
- `afferent`
- `aff`

## Subcommands

| Subcommand | Description |
| :--- | :--- |
| `list` | List registered Tier 1 source references |
| `add` | Add external reference repository |
| `remove` | Remove external reference repository |

## Flags

None

## Examples

```bash
dendrite ref list
dendrite ref add github.com/gin-gonic/gin
```
