# dendrite github-sync

Synchronize prioritized tickets and DAG dependencies to GitHub Issues

## Category

Axon & Myelin Sheath

## Aliases

- `sync-github`
- `saltatory-sync`
- `salt-sync`
- `gsync`

## Subcommands

None

## Flags

| Flag | Description |
| :--- | :--- |
| `--repo` | Target GitHub repository (owner/repo) |
| `--dry-run` | Preview issue sync without modifying GitHub |

## Examples

```bash
dendrite github-sync
```
