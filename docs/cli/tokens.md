# dendrite tokens

Inspect 24h & 7d token consumption windows and tier quotas

## Category

Terminal Boutons & Vesicles

## Aliases

- `token`
- `vesicle-quota`
- `quota`
- `vesicle`
- `tok`

## Subcommands

| Subcommand | Description |
| :--- | :--- |
| `status` | Display token spend in 24h and 7d sliding windows |
| `quota` | Display tier quotas and model rates |

## Flags

None

## Examples

```bash
dendrite tokens status
```
